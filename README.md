#### 🧩 Projects
* [**Rune3DS**](https://github.com/p0mpurin/Rune3DS): a modern 3hs fork for the 3DS with wallpaper theming and faster downloads.
* [**KuroAria DL**](https://github.com/p0mpurin/kuroaria-DL): desktop download manager on Tauri, React and aria2.
* [**JAPW**](https://github.com/p0mpurin/JAPW): Just A Pinterest Wrapper, a quiet desktop app for browsing Pinterest.
* [**Kasumi**](https://github.com/p0mpurin/Kasumi): cloud gaming client for the New 3DS.
* [**maki**](https://github.com/p0mpurin/maki): anime streaming client for the 3DS.
* [**jumptosb**](https://github.com/p0mpurin/jumptosb): browser extension to jump to any site's search bar with one key.
